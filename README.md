# 🎨 3D Animation Web Project

A simple and interactive **3D animation project** created using **HTML and CSS**.

The project demonstrates how CSS 3D transforms, animations, and transitions can be used to create visually appealing web animations without using JavaScript or external animation libraries.

## 🌐 Live Demo

🔗 [View Live Website](https://varsha0521.github.io/3d-animation-css-/)

## 📌 About the Project

This project was created to explore the capabilities of **CSS 3D transformations and animations**.

It uses HTML to structure the elements and CSS to create the 3D effects, movement, rotation, transitions, and overall visual experience.

## ✨ Features

- 🎭 3D animation effects
- 🔄 CSS-based rotations and transformations
- ✨ Smooth animations and transitions
- 🎨 Interactive visual effects
- 📱 Responsive design
- ⚡ No JavaScript required
- 🚀 Lightweight and fast

## 🛠️ Technologies Used

- **HTML5** – Used to structure the webpage
- **CSS3** – Used for styling, animations, transitions, and 3D transformations
